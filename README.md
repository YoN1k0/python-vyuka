# Repozitar pro vyuku programovaciho jazyka Python

...Dělám změny v repozitáři (programuju)...
git fetch updatuje stav vzdáleného repozitáře
git pull origin [nazev-vetve] načte změny ze vzdáleného repozitáře do větve [nazev-vetve]
git add . všechny změny uložím do stage
git commit -m "zprava" Vytvořím commit s textem zprava
git push origin [nazev-vetve] uložím změny do vzdáleného repozitáře do větve [nazev-vetve]
Hodit se mi může ještě:

git status zobrazí stav repozitáře
git log zobrazí historii commitů
git checkout [nazev-vetve] přepne branch na [nazev-vetve]. Pokud větev neexistuje, použiji přepínač -b
